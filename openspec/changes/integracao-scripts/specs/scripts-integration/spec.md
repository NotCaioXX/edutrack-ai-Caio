# scripts-integration Specification

## Purpose

Provides a dedicated user interface within Streamlit to visualize academic subject progress using `calculate_progress.py` and download performance PDF reports generated by `generate_pdf_report.py`.

## ADDED Requirements

### Requirement: Subject Progress Visualization Page
The system SHALL provide a dedicated Streamlit page displaying progress metrics for each subject calculated via `scripts/calculate_progress.py`.

#### Scenario: Student views subject progress
- **WHEN** an authenticated student accesses the Progresso page in the Streamlit application
- **THEN** the system calculates and displays task completion percentages, counters, and visual progress bars for all registered subjects

#### Scenario: Progress display with zero tasks
- **WHEN** a subject has no associated tasks
- **THEN** the page displays 0.0 percent progress without calculation errors

#### Scenario: Visitor navigation without active session
- **WHEN** an unauthenticated visitor navigates to the Progresso page
- **THEN** the application displays a warning directing the user to login on the Perfil page

### Requirement: Performance Report PDF Download Action
The system SHALL provide an interactive download control enabling students to generate and download their academic performance report in PDF format rendered by `scripts/generate_pdf_report.py`.

#### Scenario: Student downloads performance report
- **WHEN** the student triggers the report download control on the Progresso page
- **THEN** the application invokes `scripts/generate_pdf_report.py`, produces the PDF document, and offers the file for download with appropriate MIME type
